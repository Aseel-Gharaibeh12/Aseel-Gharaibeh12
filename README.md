## 📂 Featured projects

- **[CallCenterAi](https://github.com/Aseel-Gharaibeh12/CallCenterAi)**: Arabic AI voice assistant for customer service, built with Pipecat, Groq and n8n.
- **[dental-clinic-outreach-crewai](https://github.com/Aseel-Gharaibeh12/dental-clinic-outreach-crewai)**: 5 CrewAI agents that find dental clinics, collect public contacts into Google Sheets and draft personalized emails and WhatsApp messages. The first run found 40 clinics.
